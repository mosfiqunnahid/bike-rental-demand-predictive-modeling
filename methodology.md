# Methodology

This project follows a regression-based predictive modeling workflow.

## Analytical Workflow

1. Data import and cleaning
2. Feature engineering
3. Exploratory data analysis
4. Linear regression modeling
5. Polynomial regression modeling
6. AIC-based model selection
7. Residual diagnostics
8. Multicollinearity assessment using VIF
9. Model interpretation and reporting

## Main Modeling Objective

The objective is to quantify how environmental and temporal predictors influence daily bike rental demand.

## Main Model Components

- Target variable: daily bike rental count
- Predictors: temperature, humidity, wind speed, season, weather condition, working day, holiday
- Engineered feature: quadratic temperature effect

## Statistical Methods

- Multiple Linear Regression
- Polynomial Regression
- Akaike Information Criterion
- Residual Analysis
- Q-Q Plot
- Variance Inflation Factor
