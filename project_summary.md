# Project Summary

## Predictive Modeling of Bike Rental Demand

This project analyzes how environmental and temporal variables influence daily bike rental demand using regression-based statistical modeling.

## Key Skills Demonstrated

- Data cleaning and feature engineering
- Exploratory data analysis
- Multiple linear regression
- Polynomial regression
- AIC-based model selection
- Residual diagnostics
- VIF-based multicollinearity assessment
- Predictive analytics in R

## Portfolio Value

This project demonstrates applied statistical modeling and predictive analytics skills for data analyst, statistical analyst, and smart city analytics roles.
