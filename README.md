# Predictive Modeling of Bike Rental Demand

Regression-based analysis of daily bike rental demand using the **UCI Bike Sharing Dataset** to examine the effects of weather and temporal factors on urban mobility patterns.

## Methods
- Exploratory Data Analysis
- Feature Engineering
- Linear & Polynomial Regression
- AIC Model Selection
- Residual Diagnostics
- VIF Analysis

## Tools
R, tidyverse, ggplot2, Regression Modeling, AIC, VIF

## Key Insight
Temperature showed a strong non-linear effect on bike rental demand, while humidity and wind speed were negatively associated with rentals.
